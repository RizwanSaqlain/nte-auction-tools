NTE Auction Tools is an independent fan-made companion for Neverness to Everness: Going, Going, Gone. It helps you interpret two valuation gadgets and explore possible collectible combinations before bidding.

Two Devices, One Workspace

Choose a device in the homepage workspace, then use the Tool and Catalog switches to view its calculator or items. Both tools run in your browser and keep their inputs when you switch between them.

Nine-slot Average Valuation Device

This gadget reveals the average value of all nine-slot collectibles in the box. Our calculator compares your reading with 6,434 combinations of 8 supplied collectibles, allowing repeated items and groups of 1–7. You can select an item count if you know it, or leave it on Any.

We built it using simple math. The gadget displays whole numbers, so the default matching tolerance is ±2: the tool rounds both averages and compares their difference. Seven items is a practical search limit. Results show possible contents and the lowest matching nine-slot subtotal; the bid panel applies your chosen buffer to that subtotal.

Gold-rarity Valuation Device

This gadget reveals the total value of all gold-rarity collectibles in the box. The gold tool finds combinations from 50 supplied items whose values add up exactly to that total. It uses no average-value tolerance.

You can set maximum copies per item, total items, total slots, and returned results. Defaults are 5 copies, 25 items, 140 slots, and 300 results. The slot input cannot exceed the box’s 250-slot maximum; copy and item-count limits are search assumptions.

The gold catalog is ordered by increasing price. Add known minimum quantities with the +/− controls; increments respect your selected limits and entered total. Required items are highlighted in results alongside their images. Average item and slot counts describe all returned bundles across result pages, not just the visible page.

How the Gold Search Algorithm Works

The gold tool uses depth-first backtracking with branch-and-bound pruning. It sorts the catalog by decreasing price, then tries a quantity for each item within your copy, item-count, and slot limits. It follows one choice through the remaining items before backtracking to try a different quantity. This fixed item order avoids listing different arrangements of the same bundle as separate results.

Before searching, it builds a dynamic-programming table of the maximum value reachable from each remaining portion of the catalog for the available item count and slots. During the search, this upper bound lets it skip a branch when even the most valuable allowed continuation cannot reach your target.

It also skips branches when required items would exceed the remaining count, slots, or target value. Quantity choices are limited so they cannot overshoot the target. A bundle is returned only when its sum equals your reading exactly and every known minimum quantity is satisfied.

Pruning reduces unnecessary work, but large searches can still have many valid combinations. The tool stops at the result limit or time limit and marks the returned list as partial. A completed search covers all matches within the supplied catalog and your selected constraints. The algorithm runs in a background worker so the page remains responsive and you can cancel it. No branch visualizer or visualization trace is generated.

What the Results Mean

Gold searches run in a background worker and can be canceled. A time limit or result cap can leave the search incomplete; the status identifies partial results. Neither matching combinations nor their averages represent drop probabilities.

Each tool covers only the collectibles measured by its device. Neither calculates the full box value, accounts for fees or game modifiers, or checks whether item shapes fit the box. Some collectibles belong to both groups, so adding the two device values can count the same items twice.

We do not access your game account, read your screen, or place bids. Catalog values may need updating as the game changes.
